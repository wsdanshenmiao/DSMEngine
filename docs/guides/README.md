# 工作流指南

本目录用于沉淀可重复执行的工作流。每个指南都应面向具体任务。

## 默认工作流

### 小范围局部修改

1. 阅读直接受影响文件和附近已有写法。
2. 做最小范围修改。
3. 按 `docs/verification.md` 运行最小验证。
4. 汇报修改文件和验证结果。

### 复杂变更

1. 阅读 `PLANS.md`。
2. 在 `docs/exec-plans/active/` 创建 Exec-Plan。
3. 调查并把发现写回计划。
4. 以小步循环实现。
5. 验证、记录证据，并归档计划。

### 渲染或着色器变更

1. 明确 pass、pipeline、资源 owner 和 shader entry。
2. 确认 CPU 侧绑定和 shader 侧布局一致。
3. 构建 `PBR`。
4. 运行 `PBR` 并记录视觉验证结果。

### 资源或场景变更

1. 确认用户明确要求修改工程数据。
2. 在 Exec-Plan 或 review 记录中写清假设。
3. 运行相关示例或编辑器路径。
4. 记录用于验证的 scene 或 project。
