# DSMEngine Harness 文档

本目录是 Agent 使用的项目知识与工作流入口。整体遵循渐进式披露：稳定入口只负责路由，细节文档按需读取。

## 目录地图

- `architecture/`：架构说明和既有模块分析入口。
- `exec-plans/`：复杂任务的进行中计划和完成归档。
- `guides/`：可复用工作流和操作指南。
- `knowledge/`：高频复用的活知识。
- `reviews/`：Review 记录、验证证据和变更后检查。
- `verification.md`：权威验证入口。

## 维护规则

- 文档保持短小，便于按需加载。
- 优先链接源码和已有文档，避免重复编写容易过期的架构描述。
- 当重复工作流或规则发生变化时，及时更新活文档。
- 一次性调查细节应归入 Exec-Plan，不要让知识库膨胀。
