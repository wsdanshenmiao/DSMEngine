## 一页总览

ReSTIR 的核心不是“让一个像素算更多样本”，而是把别处已经计算过的候选样本，用概率严格受控的方式借给当前像素。每个像素最终只保存一个代表样本，但同时保存这个样本背后聚合过的权重信息。随着空间和时间上的反复重采样，这个代表样本的有效分布逐渐接近目标分布。

可以把整条链条理解为：

```text
廉价候选生成
    -> RIS 按目标贡献重选一个候选
    -> Reservoir 以流式、常量内存实现 RIS
    -> Temporal Reuse 借用历史 Reservoir
    -> Spatial Reuse 借用邻居 Reservoir
    -> 对最终选中样本做昂贵的可见性或路径求值
    -> 得到低样本数下的直接光或全局光估计
```

ReSTIR 的收益来自改善“有效采样分布”，不是违反蒙特卡洛收敛规律。独立样本平均只能以 1/sqrt(N) 的速度降低噪声；ReSTIR 试图让每个样本更可能落到高贡献区域，因此往往比盲目提高 SPP 更有效。但错误的 PDF、MIS、支持集或历史置信度会使结果偏亮、偏暗、闪烁，甚至在 SPP 增加时变差。

# 1. 为什么需要 ReSTIR

## 1.1 光传输积分与普通路径追踪

一个像素的光强可以视为所有可能光路贡献的积分：

```text
I_i = integral over Omega_i of f(x) dx
```

普通路径追踪从概率密度 p(x) 中抽取路径 X，并用下面的单样本估计器估计积分：

```text
<I_i> = f(X) / p(X)
```

只要 p 的支持集覆盖 f 的非零区域，这个估计器就是无偏的。问题在于 p 和 f 的形状越不匹配，方差越大。理想情况下 p 与 f 成正比，单样本就可以接近零方差；现实中我们事先不知道哪些路径携带大量能量。

增加独立样本数量虽然可靠，但噪声标准差约按 1/sqrt(N) 缩小。噪声减半通常需要约四倍样本。这在每帧只有 16.7 ms 或 33.3 ms 的实时预算下代价过高。

## 1.2 ReSTIR 的基本假设

相邻像素的积分域并不相同，但它们常常拥有相似的高贡献样本。例如，相邻地板像素可能都被同一个面光源照亮。历史帧中的同一表面点也常有相似的理想分布。因此，可以把邻居或历史的好样本转化为当前像素的候选。

关键限制是：样本不能直接复制后就当作当前像素自己采到的样本。必须重新计算它在当前像素目标函数下的贡献，并用正确权重修正不同生成分布。跨域复用时还要考虑映射是否可逆以及概率密度如何因映射发生伸缩。

## 1.3 与降噪器和 Path Guiding 的区别

后处理降噪器通常在颜色已经估计之后混合邻域颜色，无法访问生成样本时的完整概率信息，因此容易损失能量或引入其他偏差。ReSTIR 在丢弃候选之前进行分布层面的过滤和重采样，仍然掌握候选、目标函数和权重。

Path Guiding 通常从历史样本拟合一个可采样的概率分布；ReSTIR 不必显式拟合某个分布族，而是反复从已有样本中选择一个代表样本，使输出分布逐步改善。

# 2. 必要的概率基础

## 2.1 蒙特卡洛积分

对积分 I = integral f(x) dx，从可能不同的密度 p_i 中取得 M 个样本时，可写成：

```text
<I> = sum_i [ (1/M) * f(X_i) / p_i(X_i) ]
```

每个样本的贡献必须除以生成它的概率密度。采样概率越低，单次命中后所代表的积分区域越大，权重越高。

## 2.2 支持集是正确性的第一道门

函数 f 的支持集是 f(x) 不为零的所有位置。随机变量 X 的支持集是它可能以正概率或正密度生成的所有值。无偏蒙特卡洛要求：

```text
support(f) is a subset of support(X)
```

如果某类有效光路永远不可能被生成，任何权重都无法补回这部分能量。ReSTIR 更容易触犯这一点，因为邻居、历史帧、BSDF sampler 和 light sampler 的支持集可能不同。

工程检查：环境、解析灯、自发光三角形等候选域混合时，总 proposal q 必须在任何可能产生非零直接光的样本上大于零。禁用某候选域等于主动删除它的支持集，只有确认目标积分也不包含该域时才是正确的。

## 2.3 多重重要性采样 MIS

当不同技术生成样本时，直接等权平均会累加各技术最差区域的方差，并可能在单项不覆盖积分域时产生偏差。MIS 使用 m_i(x) 组合估计器：

```text
<I> = sum_i [ m_i(X_i) * f(X_i) / p_i(X_i) ]
```

要保持无偏，任意有效 x 上所有技术的 MIS 权重之和必须为 1；如果某技术无法生成 x，它的权重必须为 0。常用 balance heuristic 为：

```text
m_i(x) = p_i(x) / sum_j p_j(x)
```

注意：m_i 是对同一个假设样本 x，在所有技术下评估得到的函数。把其他候选的实际取值 X_j 混进 m_i(X_i) 通常是错误的。

## 2.4 无偏贡献权重 UCW

复杂随机过程产生的最终样本可能没有可计算的闭式 PDF。此时不必强求 1/p(X)，只要存在随机权重 W_X，使给定 X 时它的条件期望等于 1/p(X)，就仍可以使用：

```text
<I> = f(X) * W_X
```

W_X 称为 unbiased contribution weight。它不是仅由 X 决定的函数；同一个样本值可能因为不同候选集合和重采样历史而拥有不同 W_X。因此，不能把 W_X 当成 PDF 塞进普通 MIS 公式。

# 3. RIS：把多个候选压缩成一个更好的样本

## 3.1 目标函数与重采样权重

RIS 接收候选 X_1...X_M。为每个候选定义：

- m_i(X_i)：该输入的重采样 MIS 权重。
- pHat(X_i)：未归一化目标函数；它不是 PDF。
- W_Xi：输入候选的无偏贡献权重；已知 proposal PDF 时等于 1/p_i(X_i)。

重采样权重为：

```text
w_i = m_i(X_i) * pHat(X_i) * W_Xi
```

RIS 以 w_i / sum(w) 的概率选择候选 i。选中 Y 后，它的新无偏贡献权重为：

```text
W_Y = sum_i(w_i) / pHat(Y)
```

如果所有候选同分布且彼此独立，可以取 m_i = 1/M。这个 1/M 是 MIS 权重，不是为了“给 weightSum 求平均”而临时加上的归一化项。

## 3.2 为什么 pHat 不是 PDF

pHat 无需归一化。随着候选增加，RIS 输出样本的真实密度会趋近于：

```text
pBar(x) = pHat(x) / integral pHat(x) dx
```

实践中常取 pHat 为贡献颜色的标量代理，例如 luminance(unshadowedContribution)，也可以包含可见性。pHat 必须在真正贡献 f 非零的地方保持正值，否则 RIS 永远不会选中那部分积分域。

## 3.3 空样本与数值边界

如果所有 w_i 都是零，输出必须是空样本并令 W = 0。不能立即重抽到非空为止，因为这会把“本轮没有有效候选”的概率条件化掉，引入偏差。

实现时至少要防护：NaN/Inf、负权重、pHat(Y)=0、weightSum=0、proposal PDF=0、无穷远灯的几何项误用，以及面积测度与立体角测度混用。

## 3.4 Canonical Sample

当输入分布不同，候选的并集必须覆盖目标函数的支持集。工程上常保留一个 canonical sample：由当前像素自己的 sampler 直接生成，保证覆盖当前 pHat。历史和邻居样本可以改善质量，但不能取代这个正确性锚点。

对 ReSTIR DI 而言，每帧当前像素的新灯光候选就是 canonical input；历史 Reservoir 和空间邻居则是复用输入。
